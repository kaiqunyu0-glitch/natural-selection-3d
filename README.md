# 自然選擇號｜《三體II：黑暗森林》恆星級戰艦 3D 模型（同人作品）

用 Three.js **完全以程式**建出的「自然選擇」號 3D 模型網頁，可以直接用手機瀏覽器開。
所有形狀與貼圖（裝甲板縫、檢修艙口、窗燈、散熱片、木星條帶、星空）都是在瀏覽器裡即時用程式產生的，**沒有使用任何網路上現成的 3D 模型檔或圖片**。

> 這是根據劉慈欣小說《三體Ⅱ：黑暗森林》設定製作的非官方同人作品，與原著作者、出版社及任何影視／動畫版權方無關；沒有複製任何受版權保護的圖片。

## 操作
- **單指拖曳**：旋轉視角
- **雙指**：縮放＋平移
- **點一下部位**：高亮該部位並顯示繁體中文介紹（標示「原著設定／原著＋自行設計／自行設計」）
- 一段時間沒操作會自動慢速旋轉
- 按鈕：**前進四**（加大推力、艙室注滿深海加速液）、**剖面**（切開圓盤看內部球形艙室）、**回正**

## 畫質與效能
開啟時會依裝置（手機與否、CPU 核心數）選畫質，執行中每約 1.5 秒量一次幀時間，低於約 32 fps 就自動降一級：
高（陰影 2048、全解析度 bloom）→ 中（陰影 1024、bloom 半解析度、DPR 1.5）→ 低（無陰影、無 bloom、DPR 1、星星較少）→ 最低（DPR 0.75）。
右上角會顯示目前畫質與 fps。網址可加 `?q=high|mid|low|min` 指定畫質、`?auto=0` 關閉自動降級。

## 原著設定
（細節與出處見 [NOTES.md](NOTES.md)）
- 恆星級戰艦，亞洲艦隊第三分艦隊旗艦。
- 由**圓盤形主艦體**與**圓柱形發動機**兩個「完全分離的部分」組成。
- 外壁**如鏡面般光滑**，能映出木星（模型的艦體用低粗糙度金屬，並讓環境反射裡有木星）。
- 體積約相當於三艘 21 世紀最大的航空母艦，「幾乎是一座小城市」。**原著沒有給長度數字。**
- 艙室幾乎都是**規則的球形**，沒有專門的駕駛艙或艦長室；殲擊機機庫是足球場大小的球體；外壁上會出現**橢圓形入口**讓交通艇直接飛入。
- **無工質聚變推進**，全功率可達光速 15%；**前進四**時 120G，乘員要進入注滿深海加速液的**深海狀態**。
- 起航時像拖著一顆「**小太陽**」。
- 四位一體武器：伽馬射線雷射、電磁動能砲、高能粒子束、星際魚雷（原著沒寫裝在哪裡）。
- 乘員兩千多人；艦長東方延緒，章北海劫艦後組成「星艦地球」，最後在黑暗戰役中被次聲波氫彈攻擊，全艦人員罹難。

## 自行設計
- 具體尺寸（圓盤直徑約 300 m、全長約 450 m，依體積描述粗估）。
- 圓盤的雙凸剖面、艦緣環帶、航行燈、板縫與窗燈等表面細節。
- 連接圓盤與發動機的桁架主幹（原著只說兩部分分離）。
- 所有武器的外形與位置、橢圓形入口的位置。
- 「拋物面反射鏡＋焦點聚變核心」的推進器外形，以及尾焰光柱的樣子。
- 聚變燃料儲槽、散熱板、姿態控制推進器、球形艙室的數量與排列。
- 背景木星（程式生成，不是照片）、星空、太陽位置。

## 檔案
- `index.html`：頁面、介面、importmap（Three.js 0.160.0，從 unpkg CDN 載入）
- `main.js`：場景、光影、Bloom、操作、點選、畫質自動降級
- `ship.js`：戰艦的程式建模
- `textures.js`：程式產生的貼圖（法線、粗糙度、發光、木星）
- `parts.js`：各部位的繁中介紹
- `NOTES.md`：研究筆記與來源
- `.nojekyll`：讓 GitHub Pages 直接提供靜態檔

不需要建置步驟，全部用相對路徑，放到 GitHub Pages 的子路徑（例如 `/natural-selection-3d/`）即可。需要網路連線才能載入 Three.js。

## 限制
- 這是依文字描述的**詮釋**，不是官方設定；原著沒寫的地方都是自行設計。
- 細節是「程式貼圖＋少量幾何體」，近看仍看得出是貼圖，不是電影級的精細模型。
- 尾焰與 bloom 是藝術化呈現；真正的無工質輻射推進在真空中不一定看得到光柱。
- 手機上的實際流暢度取決於裝置；較舊的手機會自動降到「低」，沒有陰影與光暈。
